# HEX v0.3.3

桌面视觉与信息布局优化，让页面更稳重、数据层级更清晰。

- 加强桌面背景、卡片边界与字体层级，统一概览数字对齐及异常状态提示，提升监控信息可读性。
- 收紧桌面卡片间距，将连接、账单、到期、运行时间和备注归入底部「更多信息」，支持键盘展开与收起。
- 桌面单线路的选择、延迟与丢包信息同排显示，历史图位于下方；修复加载完成引起的卡片高度变化与返回位置偏移。
- 桌面地图默认展开，高度调整为240px，继续尊重用户保存的展开或收起选择。
- 宽屏自动布局支持四列，保留手动列数设置；兼容深色、玻璃效果和手机端布局。

## 安装

下载 `theme.tar.gz`，在 monitor-probe 后台主题管理中上传并启用 HEX；已有安装直接上传覆盖。`theme.tar.gz.sha256` 用于核对下载文件。GitHub 自动生成的源码压缩包不是主题安装包。
