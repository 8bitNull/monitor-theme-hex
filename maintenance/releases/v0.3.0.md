# HEX v0.3.0

手机端全面采用 App 布局，接入真实监控接口。

- 底部「节点 / 概览 / 设置」导航，首页紧凑卡片与常驻搜索。
- 状态、地区、分组和排序统一收进底部筛选面板；保留异常、过期、离线和流量额度提醒。
- 详情「总览 / 资源 / 网络 / 资料」四分区，节点和线路使用底部选择面板。
- 个人设置支持明暗、语言、列表密度、容量显示、探测线路和默认历史范围。
- 精修字体层级、间距、圆角和深色模式，移除选中按钮底部蓝线。
- 非图表分区暂停历史请求；历史刷新失败时保留成功数据，未知丢包不显示为零。
- 桌面布局和后台主题配置保持兼容。

## 安装

下载 `theme.tar.gz`，在 monitor-probe 后台的主题管理中上传并启用 HEX。升级同样上传覆盖即可。

`theme.tar.gz.sha256` 用于验证安装包。GitHub 自动生成的源码 ZIP 不是主题安装包。
