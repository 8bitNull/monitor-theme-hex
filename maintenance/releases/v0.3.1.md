# HEX v0.3.1

桌面与手机端精修，补齐手机桌面快捷方式图标。

- 桌面：合入第二版 Demo 的区块间距、工具栏留白、表格名称与数字对齐优化。
- 手机：网站名称与页面标题分层，时间和连接状态移至页面标题右侧；完善分组、筛选、提醒入口、底部弹层及焦点恢复。
- 详情：系统、CPU、IPv6 资料右对齐，备注按分号、逗号、顿号和换行拆成词组标签；优化线路、平滑、缩放及原始统计展示。
- 设置：管理员可查看 Hub / Agent 版本和待更新节点，重试失败检查并进入后台更新；遵循后台更新提醒开关，不自动执行升级。
- 桌面快捷方式：提供 iPhone / Android 蓝底白色 H 图标；已创建的快捷方式可能需要重新添加才能更新图标。
- README 开头与后台主题管理使用原版 HEX 宣传预览图；下方分别展示新版桌面、手机截图，全部使用本地演示数据。

## 安装

下载 `theme.tar.gz`，在 monitor-probe 后台主题管理中上传并启用 HEX；已有安装直接上传覆盖。`theme.tar.gz.sha256` 用于校验。GitHub 自动生成的源码压缩包不是主题安装包。

本次发布不会自动替换线上网站主题，也不会升级 Hub 或 Agent。

预览图修订：v0.3.1 安装包已恢复原版 HEX 宣传图，程序版本及功能不变；已安装用户可重新下载并手动上传覆盖，以更新后台预览。

## 验证

生产构建、业务测试、相关代码检查通过；桌面、手机、导航与稳定性相关浏览器回归共 39 项通过。快捷方式图标已完成文件及浏览器配置检查，尚未在 iOS / Android 实机安装验证。
