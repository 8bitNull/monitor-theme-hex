# HEX v0.3.2

桌面与手机体验优化，重点改善首次浏览、页面返回和监控信息的可读性。

- 桌面详情搜索支持候选节点与键盘切换；手机分区刷新、前进后退和详情返回保留上下文，线路延迟入口可直达对应网络历史。
- 桌面地图可折叠，短屏默认收起并保留地区筛选；个人紧凑/详细卡片与恢复默认表格列让首屏更易阅读。
- 优化手机字号、间距、异常优先级、账单折叠与短长资料对齐，修复721px地区条选中标签被挤出的问题。
- 手机网络图新增最近15/30分钟及恢复全范围，使用实际采样时间；完整范围P95/丢包统计不随缩放改变。
- 统一卡片/详情自适应网速和离线相对/绝对时间；资源容量开关保留核数与负载说明，版本缺失与无法比较分别提示。
- 修复手机延迟图关闭提示后再次点击无法显示的问题，更新README截图和完整回归验收记录。

## 安装

下载 `theme.tar.gz`，在 monitor-probe 后台主题管理中上传并启用 HEX；已有安装直接上传覆盖。`theme.tar.gz.sha256` 用于核对下载文件。GitHub 自动生成的源码压缩包不是主题安装包。

本次发布不会自动替换线上主题，也不会升级 Hub 或 Agent。
