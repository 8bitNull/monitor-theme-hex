# Three.js 平面世界地图

`src/components/ThreeWorldMap.tsx` 是可复用 React 组件；标准 Three.js 渲染器独立放在 `src/lib/mapHexRenderer.ts`。组件随父容器 Resize，支持明暗主题、鼠标视差、节点悬停及键盘选择。

依赖 React 19、Three.js（当前验证版本 0.186.1）和 TypeScript。已有 React 工程使用 `npm install three` 与 `npm install -D @types/three`。复用时保留 `ThreeWorldMap.tsx`、`ThreeMapCanvas.tsx` 及它们引用的 src/lib、src/data、src/styles 模块和相对目录；模型还引用探测质量等类型与辅助模块，不能只复制渲染器。组件本身不请求后端 API。独立使用的字体与排版由父页面设置。

```tsx
import {ThreeWorldMap} from './components/ThreeWorldMap'
import type {WorldMapNode, WorldMapConnection} from './lib/worldMapModel'

const nodes: WorldMapNode[] = [
  {id: 'tokyo', name: '东京', longitude: 139.69, latitude: 35.68,
   online: true, ping: 12, loss: 0, tx: 1_500_000, rx: 7_000_000},
  {id: 'hongkong', name: '香港', longitude: 114.17, latitude: 22.32,
   online: true, ping: 28, loss: 0.2},
]
const connections: WorldMapConnection[] = [
  {id: 'jp-hk', from: 'tokyo', to: 'hongkong', ping: 28, loss: 0.2},
]

<ThreeWorldMap
  nodes={nodes}
  connections={connections}
  theme="dark"
  style={{width: '100%', height: 420}}
  onSelect={id => console.log(id)}
/>
```

坐标为经纬度（经度 −180…180、纬度 −90…90），Ping 为毫秒，loss 为 0…100 百分比，tx/rx 为 bytes/s。未知值用 null 或省略；有效 0 与未知值不同。传入之前由业务方处理数据过期。可用 `label` 自定义地图短标签，`attention` 标记需关注的节点。Antarctica 不包含在地图陆地数据中。

`theme` 为 dark 或 light，省略时跟随 html 的 dark class。低延迟连接光斑更快，未知延迟保留线路但停止光斑；100% 丢包停止光斑。未提供连接、无效端点、离线端点或自连不生成线路。跨日期线的连接沿较短路径分段，避免横穿整个地图。

陆地由 build-time 真实 TopoJSON 多边形采样的 7,202 个 `InstancedMesh` 六边形组成，连续陆地底层与细海岸线保留小尺寸下的轮廓；正交投影与轻微视差保持平面主题。Dark 海域 #111c28、陆地 #243647、主色 #91afe0、在线 #4ade80；无 bloom 或全屏泛光。首页仅在「流量」图层有有效地区流量时显示随实际速率变化的陆地局部微光与上传下载粒子；默认「节点」图层不显示流量特效，「探测」图层独立显示当前线路质量。在线节点呼吸环独立于流量：未知流量不会生成上传下载粒子，在线呼吸环继续。

首页 `WorldMap.tsx` 使用同一 renderer，保留国家筛选和全屏。后端只提供国家而非机房坐标，因此首页标记表示地区分组，悬停可查看前两个服务器的真实探测记录。小尺寸取景紧贴完整陆地范围，地理核心保持原坐标，密集地区的文字标签避让并以细引线连接；悬停节点时视差暂停，便于读数与点击。地区流量聚合有效即时数据；Ping 来自该服务器所选线路最新有效桶，丢包来自服务端 24h 窗口统计。没有后端拓扑数据时首页不伪造城市或连接。

首页地图支持单张世界地图的自由画布浏览：拖动无限制平移，Ctrl / ⌘ + 滚轮或触控板捏合以指针位置缩放（完整适配取景的 65%…800%，默认 130%），普通滚轮继续滚动页面。背景双击放大；地区双击筛选并居中放大；右下角提供缩放比例、缩放按钮与复位；首页初始和复位均为居中的 130%，容器尺寸变化后保留居中基准。全屏内滚轮直接缩放，退出后保留首页原取景。拖动不会触发地区筛选，拖动和控件交互时暂停视差。

首页地图画布延伸到卡片边缘，继承外层圆角。标题位于左上、放大入口位于右上，简短状态图例位于左下，缩放比例与复位位于右下。保留首页概况与地图约 45:55 的比例、原有外层卡片高度（宽屏随概况等高，窄桌面 321px）。浮层使用克制的半透明海域底色，工具悬停或键盘聚焦时增强对比，减少透明度偏好使用实色。只有 WebGL 与 SVG 地理层参与视差，文字、工具和 Tooltip 固定；浮层之间的空白继续传递拖动操作。

地区速选、地图标记和节点工具栏选择器共享地区筛选；地图标记保留地区名称和数量。密集地区按显示尺寸合并，点击分组打开地区选择面板，再选择实际地区；不以偏移的标记位置代替真实地理核心。通过 ResizeObserver 测量浮层实际尺寸，地区反馈、语言和容器尺寸变化后重新布局标签与 Tooltip，并为浮层预留 6px 间距。初始世界取景保留上下安全带；平移、缩放时继续使用完整画布。上传向外、下载向内和键盘操作的说明在画布键盘聚焦时显示，避免常驻文字抢占地图。

图例「在线」表示 Agent 在线；资源高负载或部分节点离线仍使用「需关注」。所选线路的网络探测独立表达：最近桶超时、达到用户配置的延迟阈值或桶内丢包大于零时显示细虚线圈，严重延迟或超时使用红色。采样与请求缓存必须均未超过两分钟，请求失败、线路缺失或过期显示未知；15 秒检查一次时间失效。服务端 24h 丢包只作历史统计，不触发当前告警。地图可见时复用节点卡片的探测缓存、60 秒轮询和全局两请求并发限制，页面隐藏、地图离屏或卸载停止地图轮询。

鼠标离开节点后收起 Tooltip，鼠标点击选中地区不会固定 Tooltip；键盘聚焦节点时保留提示，Escape 收起。Tooltip 展示当前所选线路名称、最近探测状态、Ping 和明确标记的 24h 历史丢包。选中地区后卡片底部显示地区与节点数，桌面固定地区详情展示真实节点、上下行、当前探测和明确标注的历史丢包，可进入节点详情。可用 × 清除地区筛选，其他筛选保留。地区合计不因状态筛选被改写。

按钮缩放、指针缩放、地区双击聚焦和复位共用 260ms 三次缓出动画，SVG 地理命中层与 WebGL 使用同一中间视图。连续缩放累计目标，拖动、Resize、全屏切换及卸载打断动画；拖动保持直接跟随。系统减少动态偏好跳过缓动。

画布聚焦后支持方向键平移、+/- 缩放、0 或 Home 复位；点击背景不会显示浏览器默认外框，键盘聚焦时显示操作提示。可见地区仍有独立焦点圈，离屏地区退出 Tab 序列并隐藏其 Tooltip，原有地区筛选器始终可选。上述画布浏览属于首页 `WorldMap` 的业务交互，独立 `ThreeWorldMap` 组件与六城市演示仍使用自动适配取景。

首页与手机地图的图层和状态筛选相互独立，切换图层保留筛选和视野。「异常地区」仅统计有地理锚点、在线且当前探测有效的异常节点，按严重程度、异常数量及地区稳定顺序循环定位，进入探测图层和异常筛选。离线、过期、请求失败及只有历史丢包的节点不加入循环。

手机地图从概览进入，保留「节点、概览、设置」三个底部入口。全屏画布支持平移与双指缩放；全球取景、复位和主题工具浮在画布上。三档节点面板支持拖动和键盘高度控制，列表独立滚动；短横屏默认收起。手机复用地区详情与图层 / 状态控件，从详情返回保留视野。

独立 `ThreeWorldMap` 的公开属性没有 `layer`，上述图层、固定详情、异常循环和画布浏览由首页 / 手机业务组件提供。独立组件示例中的连接为调用方明确传入的数据；实际首页没有后台拓扑，renderer 的 `connections` 保持空数组。

Three.js 在可见、允许动态效果时懒加载；桌面 DPR ≤ 2、手机 DPR ≤ 1.5，30fps，标签隐藏或离屏时暂停。React 卸载时取消 RAF、断开 Observer、移除监听器、释放 geometry/material/instance buffers 和 WebGL context。上下文丢失或 WebGL 不可用时自动保留 SVG 底图与键盘交互；减少动态效果时不下载 Three.js。

无需地图服务密钥。几何生成：`node scripts/build-hex-map.mjs`（npm run build 已包含）；六城市独立演示：`node scripts/build-map-demo.mjs`，输出 `artifacts/hex-world-map/demo/`。演示中所有连接和指标为模拟数据，可以切换明暗、调整延迟、隐藏连接、缺失指标及卸载重挂载。

`node scripts/build-map-demo.mjs --standalone` 生成 `artifacts/hex-world-map/hex-world-map-demo.html`。这一个 HTML 含完整样式与脚本，可在本机直接打开查看动态效果，不需要部署演示服务。
