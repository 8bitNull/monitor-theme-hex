# 使用指南

本文说明 v1.2.2 的页面、设置和数据含义。稳定版本与安装入口见 [README](../README.md)。

## 安装与升级

先准备好正在运行的 monitor-probe，然后从 [最新发布页面](https://github.com/8bitNull/monitor-theme-hex/releases/latest) 下载 `theme.tar.gz`。在后台的主题管理中上传这个文件，再选择 **HEX** 启用。

升级时上传新的安装包覆盖即可。GitHub 自动生成的源码 ZIP 不是主题安装包，不能直接用于后台安装。发布页面同时提供 `theme.tar.gz.sha256`，需要时可以用它核对下载文件。

主题短名为 `hex`。页面顶部的站点名称读取后台配置；服务器名称、备注、价格、到期时间等内容也由后台管理。

地图加载时会显示进度提示；网络较慢或加载失败时，节点列表仍可使用。维护者可参考[地图性能与部署说明](MAP-PERFORMANCE.md)检查资源压缩和缓存。

## 首页怎么用

桌面节点列表上方的工具栏将节点数量单独显示，分组与地区放在筛选卡片内，卡片密度和卡片/表格切换分别成组。表格模式下，密度控件替换为表格工具；已选条件显示在工具栏下方。窄桌面允许分组换行。

电脑首页上方汇总全站节点数、今日流量、实时网速和高负载情况。点击在线、全部、离线或待更新数量，可以筛选下方的节点。「待更新」指在线但缺少实时指标或指标已过期的节点，与离线分开统计。总览数量始终覆盖全站；下方结果同时满足状态、搜索、地区、系统和分组条件，已选状态可单独清除。手机端将这些统计放入独立的「概览」页；节点页保留简洁的在线数量；离线和高负载数量仅在非零时显示，点击即可筛选。首页不显示到期、高负载和流量额度警示文字，可通过筛选或详情查看相关信息。

搜索支持服务器名称、地区和操作系统等信息。电脑首页的搜索和状态选择位于节点列表上方，可与地区、系统和分组条件组合使用；已选地区可在筛选标签中单独清除。电脑详情页的搜索会列出匹配节点，可用方向键和回车直接切换。手机端搜索框直接显示在列表上方，旁边的筛选按钮打开底部面板，可组合选择状态、地区、分组与排序。

### 卡片视图

卡片适合逐台查看服务器。电脑端默认使用紧凑卡片，可在「卡片密度」切换为详细；紧凑模式保留资源、网速、探测趋势和异常提醒，隐藏连接数、月度用量与账期和在线时长。详细模式按站点字段配置展示完整信息。桌面两种密度及手机卡片均按字段设置向游客展示公开备注，价格仅登录后显示。手机默认展示名称、系统、CPU、内存、上下行和所选线路延迟。手机设置中的「详细」列表可补充流量用量、在线时长与连接数，仍遵循站点的字段配置。完整设备和账单信息在详情查看。电脑卡片保留高负载、临近到期与流量额度提醒；离线卡片保持原有布局并整体变暗，实时数值与指示图归零，恢复在线后还原。这里的零值是离线占位，不代表新的采集结果；将指针停在卡片主入口可查看最近上报时间。点击卡片进入详情；手机卡片中的线路延迟按钮可直接进入对应网络历史。

电脑详细卡片上下行旁的曲线反映最近一分钟收到的速率变化，紧凑模式隐藏网速曲线并保留速率读数；进度条指标的容量说明也在详细模式展开。刚打开页面时，需要先积累数据。首页默认展示一条探测线路；站点管理员可在后台主题设置中改为两条或三条，更多线路在详情页查看。

### 表格视图

表格适合在电脑端横向比较多台服务器，默认显示名称、CPU、内存、硬盘、实时网速、延迟、丢包率、探测线路、流量用量与额度、到期时间和备注。手机端使用专门的节点列表，原有表格偏好仍保存在浏览器中。

电脑首页不提供表格列设置入口；此前保存在当前浏览器中的列选择仍会沿用。可用「恢复默认列」清除旧列偏好，保留当前搜索和排序。名称与状态固定保留，备注位于末列。

每页显示 20 个节点，少于一页时不显示翻页按钮。点击支持排序的表头可切换顺序，实时网速的下拉框可以选择上下行排序，延迟和丢包率分别点击对应表头排序。筛选和排序针对全部匹配节点，再按页展示；从详情页返回时会保留当前页。

备注显示时位于最后一列，按中英文分号拆成彩色标签。表格最多展示三个标签，其余以数量提示，点击可以查看完整备注。没有备注时显示“—”。

表格随整个页面上下滚动，没有单独的纵向滚动区域。横向滚动条隐藏，窄屏可滑动查看，也可使用「其他列」旁的方向按钮。

### 地图

电脑端首页顶部以约 46:54 并列展示运行概况与深色地区地图，取景为顶部筛选、图层工具及底部图例留出空间；窄桌面上下排列。地图默认按画布尺寸与节点范围自适应取景，缩放控件以此为基准显示 130%，支持拖动平移、Ctrl / ⌘ + 滚轮以指针位置缩放、双击放大及复位；普通滚轮继续滚动页面。使用「放大查看」进入全屏后跟随站点明暗，滚轮直接缩放。键盘聚焦画布后可用方向键平移、+/- 缩放、0 或 Home 复位。

默认「节点」图层展示在线状态；「流量」根据有效实时上下行显示克制的粒子与局部微光；「探测」展示当前所选线路的质量。图层与状态筛选独立，切换图层保留地区和视野。在线状态不代表探测正常，未知流量不生成活动；真实零值保留为 0。

点击地区标记、地区速选或工具栏的地区选择器可筛选节点，其他地区标记仍然可见。密集标记合并后，点击打开地区选择面板。选中地区会固定显示地区节点详情，可直接进入服务器详情；关闭地区详情保留其他筛选。表格和地图内的节点列表提供地图定位入口，定位使用国家 / 地区位置；首页节点卡片不再提供定位按钮。「异常地区」按当前有效探测的严重程度及异常数量循环定位，无有效异常时禁用。

手机从「概览」进入全屏地图，底部导航始终保持「节点、概览、设置」三个入口。地图支持单指平移、双指缩放，提供全球取景、复位与主题工具。节点面板可拖动到收起、半屏、展开三档，也可聚焦面板高度控件用键盘调整；展开后的列表独立滚动，短横屏默认收起。地区、状态和图层可在面板中操作，从详情返回保留地图视野。如果看不到地图，可在后台主题设置中检查「首页地图」是否开启。

探测异常只使用在线节点当前所选线路的最新有效采样：超时、达到配置的延迟阈值或当前桶丢包均可能标记异常。采样或请求缓存超过两分钟、线路缺失及请求失败表示未知；明确标注的 24h 丢包是历史统计，不会单独触发当前异常。减少动态效果或 WebGL 不可用时保留静态地图和筛选交互。

## 服务器详情

电脑详情页按实时状态、历史分析、流量与账期、节点资料排列。离线或数据过期时会显示最近上报时间，并隐藏失效的实时资源读数；线路探测按自己的采样时间标记是否为较旧记录。设备资料包含硬件、系统及网络信息，可用的 IP 地址支持复制。

备注在节点名称下方显示为标签，默认最多两行；内容较长时可展开或收起，没有备注时不占空间。电脑端实时资源卡下方展示系统负载、连接数和在线时长；流量、费用及到期各有独立卡片，窄桌面流量独占一行，费用和到期并排，硬件配置、系统环境与网络地址分别成组，没有地址时隐藏空卡片；今日和累计流量集中在账期区域。手机总览采用两列资源指标，流量独占一行，费用和到期并排；资料分区纵向展示各组，节点分组归入系统环境，长地址换行后仍可复制完整值。费用卡片仅登录后显示，游客视图会自动补齐剩余卡片布局；表格的费用列同样仅登录可见。流量说明跟随节点的统计方式，未设置到期或未知重置日会明确提示。

电脑与手机资源历史均通过指标切换查看 CPU、内存、硬盘和网络速率，时间范围包括 1 小时、6 小时、24 小时和 7 天。摘要展示最近采样、区间平均和区间峰值，与实时读数使用独立口径；可展开统计说明。手机总览增加资源历史预览和实时网速趋势，点击资源可进入对应指标。返回已查看的时间范围会保留最近成功数据并后台更新，刷新失败时提示状态；查看网络历史时仍保留资源预览及原更新时间。延迟历史支持 1 小时、6 小时和 24 小时，点击线路图例可以显示或隐藏曲线，拖动下方缩略图可缩小查看范围。

延迟图下方还有丢包时间轨道。显示多条线路时，可以选择要查看统计的丢包线路；均值、P95 和缩略图会跟随该选择。延迟页在前台每 30 秒同步一次，刷新失败时保留上次成功的数据并提示状态。

手机详情使用「总览 / 资源 / 网络 / 资料」四个分区。切换节点保留分区和历史时间范围，资料分区完整展示设备信息；返回时回到进入详情前的节点页或概览页，并保留筛选与滚动位置。底部页面选择写入链接，刷新和浏览器前进、后退均可恢复。节点和线路可通过底部面板切换。总览会加载资源历史预览，资料分区不请求和轮询历史数据。

## 站点设置与个人偏好

站点设置统一在后台“主题”页配置，保存在 hub 数据库中，所有访客共用，主题更新后仍保留。配色、背景、卡片与首页模块、延迟刻度等设置由站点管理员管理。

电脑访客可在页首切换明暗与语言，并保存卡片密度。手机「设置」页提供明暗、语言、紧凑或详细列表、资源容量显示、主要探测线路和默认历史范围。这些个人选择保存在当前浏览器，不写入后台。节点独立线路优先于个人主要线路，未设置时跟随后台默认值。手机列表筛选在当前页面会话中保留；电脑筛选和表格排序在标签页会话中保存。旧版站点级浏览器偏好不会覆盖后台配置。

旧版安装包的 [public/theme-config.json](../public/theme-config.json) 仍作为未保存站点设置时的初始默认值；新配置请在后台“主题”页保存。配置字段声明在 [theme.json](../theme.json)，新增默认值应同步到两处。

## 数据说明

卡片和详情中的网速按数值使用 **Kbps／Mbps／Gbps**，表格与历史图坐标保持 **Mbps**；流量用量使用 **GB／TB**。实时速率来自 Agent 上报，并不是带宽测速结果。首页离线卡片使用零值占位并标明离线；详情、表格以及过期或尚未收到的实时读数显示“—”，历史记录仍按原始采样展示；真实的零值仍显示为 0。总览中的“暂无实时数据”提示表示部分在线节点暂时没有可用读数，网速合计只统计有有效数据的节点。

流量用量遵循后台配置的计费方式和重置日，不一定从每月 1 日开始。没有流量额度限制时显示“∞”。费用和到期信息取自后台，不会根据流量自动推算。

延迟颜色用于帮助阅读。默认统一使用 0–500 ms 刻度，从 150 ms 起显示黄色、300 ms 起显示红色，可在后台主题设置中修改；这些设置不会改变后台的告警阈值。手机网络摘要的 P95 基于完整请求范围内有效采样桶的原始延迟中位值，丢包率使用后端提供的完整范围统计；缩放仅改变图表视野，不改变摘要统计范围。未提供丢包统计时显示未知，不会当成 0%。手机点击「调整视野」可展开最近 15 分钟、最近 30 分钟和起止时间滑杆；收起后保留已选范围，点击「恢复全范围」可重置，以最后一条实际采样为基准。「抑制尖峰」开关直接显示在时间范围旁，仅改变图线，不修改原始采样或摘要。单条可用线路不再重复显示图例，多线路仍可比较。

高负载记录是当前浏览器的本地观测：CPU 达到 85% 时开始记录，低于 80% 时标记恢复。页面关闭期间不会继续监测，记录也不跨设备同步。长期告警仍应使用服务端的告警功能。

## 手机桌面快捷方式

安装新版主题后，使用 iPhone Safari 的分享菜单或 Android 浏览器菜单选择「添加到主屏幕」，即可使用与手机端一致的蓝底白色 H 图标。建议从网站首页添加；已有快捷方式可能需要删除后重新添加以刷新图标。此功能需要联网使用，不提供离线监控。

## 管理员版本与更新

管理员登录后，在手机端「设置 → 应用 → 版本与更新」查看 Hub 和 Agent 版本、待更新节点及发布说明。提醒点遵循后台开关；版本查询失败、尚未上报和无法比较会分别提示。升级需进入后台执行，主题不会自动升级 Hub 或 Agent。
