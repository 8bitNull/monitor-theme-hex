# 全景驾驶舱工作台（Cockpit Console Layout）设计规范

## 1. 概述与设计目标

### 1.1 背景与用户痛点
当前 `monitor-theme-hex` 在移动端与紧凑视图上已具备良好的触控与信息呈现能力，但在现代桌面大屏（1080P、2K 及超宽屏，≥1024px）下存在以下瓶颈：
- **首页单向长瀑布流**：用户进入首页必须先向下滚过大幅世界地图才能查看节点卡片；地图与卡片上下割裂，缺乏一体化的中控联动体验。
- **节点详情页长单列堆叠**：大屏两侧留白严重（利用率不足 40%），硬件参数与多维遥测图表在垂直方向长幅排布，用户需要频繁滚轮核对数据。

### 1.2 核心目标
1. **中控化驾驶舱（NOC Cockpit）**：在桌面端（`≥1024px`）将首页与详情页升级为高密度、高信息量、左右联动的现代控制台。
2. **首页分栏联动**：左侧 65% 主区域承载节点卡片与快速检索；右侧 35% 固定中控台承载世界地图 HUD、瞬时流量排行榜与告警中心；支持点击地图地区瞬间联动筛选左侧节点。
3. **详情页双栏工作台**：左侧 30% 固定主机名片（实时仪表盘、硬件清单、网络规格、账单到期）；右侧 70% 展开多线路延迟波形与全部资源历史趋势图表。
4. **完全可控与优雅降级**：
   - 在偏好设置中增加“前台驾驶舱模式 (Cockpit Mode)”开关，默认开启，用户可随时一键切回经典单流瀑布视图。
   - 在平板和移动端（`<1024px`）自动平滑回退至现有单列触摸流，完全不影响现有移动端手势与交互。

## 2. 偏好设置与状态管理体系

### 2.1 偏好项定义 (`src/lib/appearance.ts`)
```typescript
export interface Preferences {
  // ...已有配置项
  cockpitMode: boolean; // 是否启用桌面驾驶舱双栏模式，默认 true
}

export const defaults: Preferences = {
  // ...已有默认值
  cockpitMode: true,
};
```

### 2.2 页面属性注入与响应式触发
- 在顶层或根节点注入属性：`html[data-cockpit="true"]` 或 `<div id="app" data-cockpit="true">`。
- CSS 响应式断点统一规定为 `@media (min-width: 1024px)`：
  - 当且仅当 `[data-cockpit="true"]` 且视口宽度 `≥1024px` 时，激活双栏驾驶舱栅格体系。
  - 当视口宽度 `<1024px` 时，忽略双栏栅格，平滑降级为现有的单列触摸流。

### 2.3 外观设置面板 (`src/components/Preferences.tsx`)
- 在“外观与布局”区域新增开关项：
  - 标签：`前台驾驶舱模式` / `Cockpit Console`
  - 说明：`在大屏（≥1024px）下开启专业双栏中控布局，提高大屏利用率；关闭时恢复经典单流瀑布视图。`
- 国际化支持 (`src/lib/en.ts`)：
  - 增加 `"Cockpit Console": "驾驶舱模式"`
  - 增加 `"Enable dual-column cockpit console on wide screens": "大屏下启用双栏中控台"`

### 3.2 地图与列表双向中控联动 (Map-to-List Linkage)
- 当用户在右侧地图上点击某个地区的标记点（例如 `HK`、`JP`、`US`）：
  - 触发 `onSelectRegion(region)` 联动，左侧节点列表即时筛选并平滑滚动至首个命中节点。
  - 左侧展示醒目的清除筛选提示，右侧地图高亮当前选中的区域。

### 3.3 材质与微光规范
- 继承 `v0.3.7` 赛博微光毛玻璃材质规范：
  - 侧栏容器 `.cockpit-aside` 拥有晶体切面高光描边（`--cyber-border-gradient`）与柔和模糊（`backdrop-filter: blur(16px)`）。
  - 深色模式下与底层的深空黑曜石（`#0a0d14`）及对角暗夜柔光径向渐变（`--mesh-gradient`）融为一体。

### 4.2 视觉与交互优势
1. **视线焦距优化**：在大屏（≥1024px）下，左侧主机名片常驻，右侧图表充分舒展，单屏尽收眼底，无需在长单列中来回寻找硬件参数。
2. **图表自适应缩放**：右侧图表容器使用响应式 `ResponsiveContainer`，随着侧栏宽度动态计算宽度，保持渲染平滑无晃动。

## 5. 响应式与无障碍保障

### 5.1 响应式矩阵
| 设备视口 | 宽度断点 | 首页布局 | 详情页布局 |
| :--- | :--- | :--- | :--- |
| **超宽屏 / 2K** | ≥1440px | 65% 卡片网格 + 35% 吸顶中控台 | 30% 主机名片 + 70% 遥测图表工作台 |
| **标准桌面 / 笔记本**| 1024px - 1439px | 60% 卡片网格 + 40% 吸顶中控台 | 35% 主机名片 + 65% 遥测图表工作台 |
| **平板竖屏 / 手机** | <1024px | 单列流式（经典触摸流与沉浸地图抽屉） | 单列垂直堆叠与折叠资料卡 |

### 5.2 无障碍与减动效保障
- 继承 `@media (prefers-reduced-motion: reduce)`：禁用平滑滚动过渡与脉冲动效。
- 继承 `@media (prefers-reduced-transparency: reduce)`：禁用毛玻璃滤镜，回退为高对比度纯色表面。
- 严守 **0 像素横向溢出**，确保移动端及小窗缩放无水平滚动条。
