# 历史归档

这里集中保留历次设计与验证资料，方便查阅历史变化。当前主题入口、使用方式和展示图见 [README](../README.md)。

| 目录 | 内容 |
|---|---|
| `design/` | 历史设计稿、交互原型、体验审查与证据 |
| `screenshots/` | 旧版本与专项验证截图 |
| `benchmarks/map/` | 地图性能和资源传输基准 |

归档保留原始版本与测试条件，不能直接代表当前版本的行为或性能。正式验收记录见 [维护资料](../maintenance/README.md)。

相关历史脚本仍放在 `scripts/`，其中的归档路径已经更新。执行前核对脚本要求的演示端口和浏览器；这些工具可能更新归档中的证据文件。新的临时验证文件放入本地 `artifacts/` 或 `tests/artifacts/`。

移动端历史原型可从仓库根目录启动：

```sh
node archive/design/serve-mobile-app-demo.mjs
```

原型页面位于 `http://127.0.0.1:4188`，与主题演示服务分别运行。
